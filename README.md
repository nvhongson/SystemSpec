# My System Specification #

System Specification Tool in C++ 🖥️

A lightweight C++ utility that displays key system specifications such as CPU info, memory usage, operating system details, and more.

This project uses native system calls and libraries to retrieve hardware and OS information, offering a basic overview of the system's configuration. It's useful for learning how to interact with low-level system APIs in C++.

Planned features include cross-platform support, GPU info, and export to file.
